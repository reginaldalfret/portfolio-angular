# Reginald Alfret V - Portfolio (Angular Edition)

> Standalone Angular implementation of Reginald Alfret's obsidian liquid-glass resume portfolio with 30 merged open-source PRs across Google, Apple, Microsoft, Meta, AWS, NVIDIA, NASA, and Netflix.

## Tech Stack
- **Framework:** Angular 19/22 (TypeScript 6.0)
- **Architecture:** Standalone Component · Angular Signals · Control Flow Syntax (`@if`, `@for`)
- **Styling:** Tailwind CSS (Obsidian liquid-glass with Angular red glow `#DD0031`)
- **Deployment:** Vercel Static Hosting & Local Dev Server

## Multi-Stack Architecture
Part of Reginald Alfret's 7-stack portfolio ecosystem:
1. **Next.js 14** (TypeScript, React 18, App Router)
2. **Nuxt 3** (Vue 3, TypeScript, Vite)
3. **Django 5.2** (Python 3.13, Django MVT)
4. **Spring Boot 3.4** (Java 21, Spring MVC, Thymeleaf)
5. **Laravel 12** (PHP 8.4, Blade SSR)
6. **Ruby on Rails 8** (Ruby 3.4, ActionView ERB)
7. **Angular 19/22** (TypeScript, Standalone Component & Signals)

## Local Development
```bash
# Clone
git clone https://github.com/reginaldalfret/portfolio-angular.git
cd portfolio-angular

# Install dependencies
pnpm install

# Run dev server
pnpm start -- --port 8085
```
Navigate to `http://localhost:8085`.
